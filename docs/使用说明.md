# 积分商城 · 使用说明

## 1. 这是什么

「积分商城」是接入 AI 助手的积分运营工具：

- **我的账户**：余额、等级、累计获得/消费、即将过期积分（红色预警）；
- **赚分任务**：签到/浏览/评价/邀请/连续签到，带每日上限，一键完成；
- **兑换商城**：8 款商品按分类筛选，标注积分成本、市场价、库存（<20 红色告警）；
- **积分流水**：每笔加分/扣分全程留痕；
- **AI 助手（points-copilot）**：查积分、要推荐、做任务、下兑换单、给兑换码。

## 2. 启动步骤

前置：本机已运行 DSH 宿主（`127.0.0.1:8090`），JDK 17+、Maven 3.8+。

```bash
mvn clean package -DskipTests
java -Dserver.port=18090 -jar points-app/target/points-app-1.0.0-SNAPSHOT.jar

bash install_plugin.sh \
  points-plugin/target/points-plugin-1.0.0-SNAPSHOT.jar \
  points-copilot 1.0.0-SNAPSHOT \
  points-plugin-1.0.0-SNAPSHOT.jar "积分商城助手"

open http://127.0.0.1:18090/
```

## 3. 页面功能

| 区域 | 操作 |
|------|------|
| 我的账户 | 只读 |
| 赚分任务 | 「去做任务」按钮，完成后余额即时到账 |
| 兑换商城 | 分类标签筛选；「立即兑换」扣分并弹出兑换码 |
| 积分流水 | 只读，最近在前 |
| AI 助手 | 右侧面板，Enter 发送 |

## 4. AI 助手常用指令

| 你说 | AI 做 |
|------|------|
| “我的积分还能换什么” | 调 `points_account` + `goods_list` 给可兑清单 |
| “推荐一个最值的兑换” | 按市场价/积分成本算性价比，给单件与组合两档建议 |
| “帮我兑换保温杯” | 校验余额库存 → 兑换 → 回兑换码与剩余积分 |
| “帮我做今天的签到任务” | 调 `task_ops(action=do)`，报奖励与最新余额 |
| “积分快过期怎么办” | 结合临期分数推荐小面额热兑商品 |
| “查我的积分流水” | 调 `points_ledger` 逐笔列明细 |

## 5. 常见问题

**Q1：AI 无回复？**
确认 DSH 已启动且 `points-copilot` 为 ACTIVE：`curl --noproxy '*' 127.0.0.1:8090/api/harness/plugins`。

**Q2：兑换提示积分不足？**
正常拦截。可以让 AI 推荐可兑范围，或先做任务攒分（邀请好友 +300 最高）。

**Q3：库存不足？**
商品库存扣到 0 后按钮禁用；演示数据重启即恢复。

**Q4：数据持久化？**
当前为内存演示数据，重启还原；数据层在 `PointsStore`，可替换为数据库。
